# Provenance

The anatomical heart artwork, fictional workout samples, visual treatment, and two-part pulse were carried over from the same author's [Athlete Living Atlas](https://github.com/sivalinb/athlete-living-atlas) project for the requested Grafana integration. The heart image is an illustration; it is not patient imaging.

The data-hall SVG, simulated rack measurements, schemas, and Grafana adaptations were created for this exploration. The 24 racks and their warning/offline examples are fictional.

This repository contains panel source and dashboard configurations, not redistributed plugin binaries. External components are installed separately:

- [Grafana](https://github.com/grafana/grafana)
- [HTML Graphics](https://github.com/gapitio/gapit-htmlgraphics-panel)
- [SQLite data source](https://github.com/fr-ser/grafana-sqlite-datasource)

Each external component retains its own license and terms.
